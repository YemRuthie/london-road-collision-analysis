# Data

This project uses UK Department for Transport road collision open data covering:

- 2021
- 2022
- 2023

The three annual collision datasets were combined using Power Query and filtered to Metropolitan London.

The raw datasets are not included in this repository due to their size.

## Main fields used

The analysis uses variables including:

- collision year
- collision severity
- number of casualties
- number of vehicles
- date and time
- latitude and longitude
- weather conditions
- light conditions
- road-surface conditions
- road type
- speed limit

Several coded variables were converted into readable reporting fields during the Power Query transformation process.
